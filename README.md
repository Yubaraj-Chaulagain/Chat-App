# Chat App APK
WebView Android app for:
https://fulkumari.com.np/sheettoweb/App/Chat

## GitHub
Upload this project to a GitHub repository, open **Actions**, run **Build Chat App APK**, then download the `ChatApp-debug-apk` artifact.

Package: `np.com.fulkumari.chatapp`
Version: `1.0`
